# English glossary (뚝 카이로 클리닉 → Crack! Chiro Clinic)

Every translator uses these exact names. Keys in `src/i18n/en/*.json` are the Korean source text exactly as written in
the code (trimmed); values are the English line. Keep every `{placeholder}` and every `\n` from the source.

## Tone
- Absurd, slapstick, B-movie comedy ("병맛"). Short, spoken, punchy. Like a dumb mobile game that knows it is dumb.
- Never suggest players should try real neck/back adjustments. Exaggeration is the point; it is a cartoon.
- No emoji. No Korean characters in English values. Keep it about as long as the Korean (UI space is tight on phones):
  buttons 1-3 words, chips very short, stamps 1-3 words.
- Swearing in 목뽑기 (neck pull) lines stays at the same level, as mangled English swears: "son of a bi-i-i-itch",
  "holy shhhhhit", "fuuuu-", "freakin'". Keep the misspelled/stretched style.
- Puns welcome when they fit. Do not explain jokes.
- Korean honorific nuance becomes friendly/casual English. "원장(님)" = "Doc".
